`src/app.tsx`. The starter already supplies the theme, styles, and font.

Read `src/app.tsx` before editing it. Use its existing `Text` component and task code markers. The
requested change is limited to the text inside that component. Keep the imports, component
structure, and other application files unchanged. No new package is needed.

## Check and repair

After the edit, read `src/app.tsx` again. Check that the existing `Text` component contains exactly
`Ready for review`. Check that the task code markers remain. Check that no other application file
changed and no package was added.

Run `vp run verify` from the project root. If your edit caused a failure, repair that edit and run
the check again. Keep the repair within the original task scope. In the final response, state the
change and the check result. Report any failure that remains.
