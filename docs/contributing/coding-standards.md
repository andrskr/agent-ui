# Coding Standards

This document lists the coding standards for this repository.

## Language

Write all documentation in ASD-STE100 Simplified Technical English. Use short sentences. Give one
instruction per sentence. Use active voice.

## Tooling

Use Vite+ (`vp`) for all commands. Run workspace commands from the repository root.

- Run `vp install` after you pull remote changes.
- Run `vp check` to format, lint, and type check your changes.
- Run `vp test` to run the tests.
- Run `vp run verify` before you hand off work.

## Code

- Match the style of the code around you.
- Keep the comment density, naming, and idiom of the existing file.
- Do not add speculative packages or abstractions.

## Tests

Tautological tests are considered harmful.

## Commits

- Write commit messages in Simplified Technical English.
- Keep each commit focused on one change.
